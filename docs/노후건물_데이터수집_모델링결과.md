## 2. 1차 실험 — 3클래스 분류 (우수 / 보통 / 불량)

### 2-1. 라벨 체계·전처리·분할

| 항목 | 내용 |
| --- | --- |
| 라벨 | 원본 3등급 그대로 사용 (우수 / 보통 / 불량) |
| 이미지 전처리 (오프라인) | 원본 → **224×224 정방형 강제 리사이즈** (종횡비 왜곡 있음) 캐시 |
| 증강 (train만) | 좌우 반전 50% + 밝기·대비 ±0.1 지터 + ImageNet 정규화 |
| 분할 | 그룹(촬영 영상) 단위 70/15/15, 등급별 층화, seed 42 — 그룹 중복 0 검증 |
| Test 세트 | 5,558장 (우수 501 / 보통 620 / 불량 4,437) |
| 학습 방식 | 2단계 전이학습 (백본 동결 baseline → 부분 해제 fine-tune, 차등 학습률) |
| 불균형 대응 | 클래스 가중치 CrossEntropy (예: [3.79, 2.95, 0.42]) |

추가 시도 (모두 개선 실패):

| 시도 | 결과 |
| --- | --- |
| 오프라인 증강 (보통 클래스 증량, aug2/aug3) | 전 조합에서 무증강 대비 성능 하락 — 보통 F1 개선 실패 |
| 로짓 bias 보정 (보통 recall 확보 목적) | bias 1.6에서 보통 recall은 오르나 전체 Macro F1 급락 (0.6702 → 0.6224) |

### 2-3. 관찰 및 결론

- 불량 F1은 0.94+ 도달, 그러나 **보통 F1이 어떤 방법으로도 0.44를 넘지 못함** (우수·불량 사이 경계가 시각적으로 모호)
- 멘토 피드백을 반영해 **"정상(우수) vs 불량(보통+불량 병합)" 이원화로 과제 전환** 결정

## 3. 2차 실험 — 이원화 분류 1세대 (입력 224)

### 3-1. 라벨 체계·전처리

| 항목 | 내용 |
| --- | --- |
| 라벨 | **이원화**: 우수(0) vs 불량(1, 보통+불량 병합) — 전체 분포 우수 3,266장(8.8%) / 불량 34,019장(91.2%) |
| 전처리·분할 | **1차 실험과 동일** (224 정방형 리사이즈, 동일 split 재사용) |
| Test 세트 | 5,558장 (우수 501 / 불량 5,057) |
| 핵심 지표 | 1:10 불균형 → Accuracy 대신 **우수 F1 / Macro F1** 기준 |
| 불균형 대응 | 클래스 가중치 [5.68, 0.55] |

### 3-2. 결과 (Test 5,558장)

| 모델 | Accuracy | 불량 F1 | 우수 F1 | Macro F1 | 단일 추론 지연 |
| --- | --- | --- | --- | --- | --- |
| **ResNet-50** | **95.90%** | **0.9776** | **0.7620** | **0.8698** | 5.11ms |
| ResNet-18 | 95.18% | 0.9735 | 0.7320 | 0.8528 | 1.96ms |
| MobileNet-V2 | 93.97% | 0.9666 | 0.6941 | 0.8303 | 4.09ms |
| EfficientNet-B0 | 93.43% | 0.9636 | 0.6636 | 0.8136 | 6.42ms |

결정 임계값 보정 (validation에서 불량 recall ≥ 0.85 제약으로 탐색):

| 모델 | 선택 임계값 | 보정 후 Macro F1 | 변화 |
| --- | --- | --- | --- |
| MobileNet-V2 | 0.30 | 0.8446 | **+0.0143 (유일한 유의미 개선)** |
| ResNet-18 | 0.45 | 0.8532 | +0.0004 (무변화 수준) |
| ResNet-50 | 0.34 | 0.8687 | -0.0011 |
| EfficientNet-B0 | 0.26 | 0.8084 | -0.0052 |

### 3-3. 관찰 및 결론

- 이원화로 3클래스 대비 성능 대폭 개선 (최고 Macro F1 0.7054 → 0.8698)
- 그러나 **우수 F1 0.76이 병목** — 우수 501장 중 136장(27.1%)을 불량으로 오분류
- 원인 진단: 224 정방형 왜곡으로 미세 결함 디테일 손실 + 결함 위치와 무관한 크롭 → **전처리를 재설계한 v3로 이행**

## 4. 3차 실험 — v3 (전처리 재설계, 입력 448)

### 4-1. 전처리 개선 내용

| 항목 | 이전 (1·2차) | v3 |
| --- | --- | --- |
| 이미지 캐시 | 224×224 정방형 강제 리사이즈 (종횡비 왜곡) | **종횡비 유지, 짧은 변 768px** 다운스케일 (LANCZOS, 14GB 중립 캐시) |
| 학습 입력 | 224 | **448** (짧은 변 512 리사이즈 → 448 크롭) |
| 크롭 방식 | 결함 위치 무관 | **결함 인지 크롭(defect-aware crop)** — 어노테이션 bbox 중심으로 크롭 유도 (중심 지터 ±25%) |
| 어노테이션 활용 | 미사용 | polygon → bbox 변환 후 크롭 유도에 사용 |
| 색상 증강 | 밝기·대비 ±0.1 | 동일 유지 + **색조·채도 변형 금지 명문화** (철근 노출의 녹 색 신호 보존) |
| 평가 전처리 | 224 정방형 | 512 리사이즈 → 448 센터크롭 (결함 완전 누락률 0.45% 실측 후 채택) |
| 분할 | 등급별 층화 | **결함종류×이원화 라벨 층화**로 재분할 (그룹 단위, seed 42, 누수 0) |

- 라벨은 2차와 동일한 이원화 유지 (우수 0 / 불량 1)
- **재분할로 Test 세트가 변경됨**: 5,676장 (우수 448 / 불량 5,228) — 이전 세대와 직접 수치 비교 시 주의

### 4-2. 학습 설정

| 항목 | 값 |
| --- | --- |
| 학습 방식 | 2단계 전이학습 — baseline 5ep (head만, LR 1e-3) → fine-tune 최대 15ep (부분 해제, head 1e-4 / backbone 1e-5, patience 3) |
| Optimizer / Scheduler | Adam (ConvNeXt만 AdamW) / CosineAnnealingLR |
| Loss | CrossEntropy + 클래스 가중치 [5.44, 0.55] |
| 배치 / 기타 | batch 64 · AMP · seed 42 · BN 이동통계 동결 |
| 모델 선택 기준 | Validation Macro F1 최대 시점 저장 |

### 4-3. 결과 (Test 5,676장: 우수 448 / 불량 5,228)

백본 6종 + 전처리 변형(CLAHE 대비 향상) 1종, 총 7개 실험.

| 실험 | 백본 | Accuracy | 불량 F1 | 우수 F1 | Macro F1 | 단일 추론 지연 | 배치 처리량 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **v3cta** | **ConvNeXt-Tiny** | **98.54%** | **0.9921** | **0.9081** | **0.9501** | 4.48ms | 359.0장/s |
| v3ctclahe | ConvNeXt-Tiny + CLAHE | 97.80% | 0.9880 | 0.8686 | 0.9283 | 4.49ms | 359.5장/s |
| v3eb2a | EfficientNet-B2 | 97.87% | 0.9884 | 0.8654 | 0.9269 | 7.02ms | 548.3장/s |
| v3r18a | ResNet-18 | 97.73% | 0.9876 | 0.8608 | 0.9242 | 2.77ms | 932.4장/s |
| v3eb0a | EfficientNet-B0 | 97.71% | 0.9875 | 0.8590 | 0.9233 | 4.94ms | 764.0장/s |
| v3r50a | ResNet-50 | 97.48% | 0.9863 | 0.8474 | 0.9168 | 4.43ms | 402.9장/s |
| v3mv2a | MobileNet-V2 | 95.89% | 0.9774 | 0.7736 | 0.8755 | 3.17ms | 1079.5장/s |

주요 관찰:

- **ConvNeXt-Tiny(v3cta)가 전 지표 1위.** 병목이던 우수 F1이 0.9081까지 상승 (2세대 최고 0.7620 → 0.9081). 우수 448장 중 410장 정분류(오분류 8.5%)
- **CLAHE 전처리는 오히려 성능 하락** (Macro F1 0.9501 → 0.9283) — 대비 향상이 이 데이터에서는 이득 없음
- ResNet-18은 Macro F1 0.9242를 유지하면서 지연 2.77ms로 최속 — 경량 배포 시 대안
